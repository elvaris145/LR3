
# Лабораторная работа №3

## Описание проекта

Программа написана на языке C#.

Проект представляет собой консольное приложение с меню, которое включает несколько функций.

## Возможности программы

1. **Отгадай ответ** — игра, в которой пользователю необходимо вычислить правильный ответ по заданной формуле.
2. **Об авторе** — вывод информации об авторе программы.
3. **Сортировка массива** — создание массива случайных чисел и сравнение двух алгоритмов сортировки:
   - Сортировка пузырьком (Bubble Sort).
   - Сортировка Шелла (Shell Sort).

## Используемые технологии

- C#
- .NET
- Visual Studio Code

## Запуск программы

Для запуска программы необходимо открыть проект в Visual Studio Code и выполнить его через .NET.
